🏪 Store Management System – Data Analytics Project

📌 Project Overview

The Store Management System – Data Analytics Project is an end-to-end data analytics project developed to analyze store performance and generate meaningful business insights.

The project uses Python and Power BI to perform data cleaning, Exploratory Data Analysis (EDA), statistical analysis, visualization, and business analysis.

The analysis focuses on understanding sales, profitability, customer behavior, product performance, regional performance, delivery status, payment methods, and inventory patterns.


🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales and profitability.
- Understand customer purchasing behavior.
- Identify high-performing product categories.
- Analyze regional sales and profit performance.
- Compare different customer segments.
- Analyze delivery and payment patterns.
- Study inventory and reorder information.
- Identify monthly sales and profit trends.
- Analyze relationships between numerical variables.
- Identify meaningful business patterns.
- Build an interactive Power BI dashboard.
- Generate data-driven business insights.

🔍 Exploratory Data Analysis

The project follows a structured Exploratory Data Analysis process to understand the dataset and identify meaningful patterns.


1. Data Exploration

The initial analysis was performed to understand:

- Dataset structure
- Number of records
- Data types
- Statistical summaries
- Categorical and numerical variables

Python and Pandas were used for the initial exploration.


2. Data Quality Analysis

The data was checked for:

- Missing values
- Duplicate records
- Incorrect data types
- Unique values
- Data consistency

Date-related information was also prepared for time-based analysis.


3. Categorical Analysis

Categorical variables were analyzed using appropriate visualizations such as:

- Bar charts
- Count plots
- Distribution charts

This analysis helps understand customer segments, product categories, regions, payment methods, and delivery status.


4. Numerical Analysis

Numerical variables were analyzed using statistical measures such as:

- Mean
- Median
- Minimum
- Maximum
- Standard deviation

Visualizations such as:

- Histograms
- Box plots
- Distribution plots

were used to understand data distributions and identify potential outliers.


📈 Business Analysis

🛒 Product Category Analysis

Product categories were analyzed based on:

- Total Sales
- Total Profit
- Order Count
- Profitability

This analysis helps identify categories contributing significantly to overall store performance.


🌎 Regional Analysis

Store performance was analyzed across different regions based on:

- Sales
- Profit
- Order volume

This helps understand regional differences in business performance.


👥 Customer Segment Analysis

Customer segments were analyzed using:

- Total Sales
- Total Profit
- Order Count
- Average Sales
- Average Profit

This analysis helps understand purchasing patterns across different customer groups.


📅 Time Series Analysis

Date-based analysis was performed to identify trends in store performance.

The project analyzes:

- Monthly Sales
- Monthly Profit
- Monthly Orders

Time-series visualizations help identify changes and patterns in business performance over time.


🔗 Correlation Analysis

Correlation analysis was performed to understand relationships between important numerical variables.

A correlation matrix and heatmap were created using Seaborn to visualize the strength and direction of relationships between variables.


📦 Inventory Analysis

Inventory-related information was analyzed to understand:

- Stock availability
- Reorder requirements
- Inventory patterns
- Automatic reorder status

This analysis provides insights into inventory management and stock replenishment.


🚚 Delivery & Payment Analysis

The project analyzes different delivery statuses to understand order fulfillment patterns.

It also analyzes payment methods to understand customer payment preferences.

These analyses help provide a better understanding of operational and customer behavior.
